# 🧠 NeuroAI – AI Medical Report Analyzer

## 📌 Overview

NeuroAI is an AI-powered Medical Report Analyzer that allows users to upload PDF medical reports, extract text, detect abnormal test values, and generate an easy-to-understand summary with health recommendations.

The project is built using FastAPI for the backend and React (Vite) for the frontend.

---

## 🚀 Features

- Upload PDF medical reports
- Extract text from digital PDFs
- OCR support for scanned PDFs
- Detect abnormal blood test values
- AI-generated medical summary
- Health recommendations
- Modern React frontend

## ⚙ Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
